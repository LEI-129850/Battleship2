# Checkstyle: nomes de pacotes (129834)

## Regra escolhida
A Tarefa 2.B é implementada com a regra exclusiva `PackageName`, que valida nomes de pacotes. Na main consultada (b8aa10b68ddcb2e46cb204c6f27bc0f14cacf7a5), os restantes elementos usam `ParameterName` (129830, Flavio Santos), `TypeName` (129843, Martim Correia) e `MethodName` (129850, Gonçalo Sobral). Nenhum desses ficheiros usa PackageName.

O padrão `^[a-z]+(\.[a-z][a-z0-9]*)*$` exige um primeiro segmento só com letras minúsculas e segmentos seguintes começados por minúscula, seguidos de minúsculas ou algarismos. Não permite maiúsculas nem underscores. Exemplos válidos: `battleship`, `restserver`, `battleship.checkstyle129834`. Exemplo inválido: `battleship.Checkstyle129834`.

## Limitações
O Checkstyle verifica a forma do nome, não se o pacote tem um nome significativo ou representa uma divisão adequada das responsabilidades. Um nome como `abc` passa o padrão, apesar de poder ser pouco informativo. A regra PackageName, por si só, não verifica se a declaração corresponde à pasta nem exige uma declaração de pacote em todos os ficheiros.
